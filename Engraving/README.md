# Engraving

`Scores/` contains the authoritative MusicXML/PDF delivery material. `Finale/Source/` contains the editable Finale `.musx` sources; `Finale/Backups/` retains the dated Finale backup lineage. `Score-Study/` contains analytical and reference material derived from those scores.

Runtime copies inside `Software/` are generated delivery assets; revise the score here first, then use `Operations/Scripts/` to regenerate show-control and runtime outputs.
